# Elementi necessari per il portale di studio sul diritto tributario

- **Sistema operativo**: Windows 11 (64 bit).
- **Python**: Versione 3.10 o successiva (disponibile gratuitamente da [python.org](https://www.python.org/downloads/windows/)).
- **Visual Studio**: Edizione Community con il componente "Sviluppo desktop con Python" oppure Visual Studio Code con estensione Python (entrambi gratuiti).
- **Git**: Facoltativo ma consigliato per clonare e aggiornare il progetto.
- **Librerie Python**: installabili con `pip` tramite il file `requirements.txt` fornito.
  - `streamlit`: interfaccia web interattiva per il portale.
  - `duckduckgo_search`: interrogazioni mirate al motore di ricerca DuckDuckGo.
  - `pandas`: gestione e trasformazione dei dati restituiti dalle ricerche.
  - `fpdf2`: generazione di eventuali report in formato PDF.
- **Browser web moderno**: per visualizzare l'interfaccia del portale (Edge, Chrome, Firefox, ecc.).
